# DIO

Projetos e exercícios feitos em bootcamps da **DIO (Digital Innovation One)**, em **Machine Learning** e **Python**.

## Machine Learning

| Projeto | O que faz |
| --- | --- |
| [Detecção de animais marinhos com YOLO](./Machine%20Learning/Deteccao%20de%20Animais%20Marinhos%20YOLO.ipynb) | Treino de um modelo de detecção de objetos para identificar animais marinhos em imagens |
| [Predição de diabetes](./Machine%20Learning/Predi%C3%A7%C3%A3o%20de%20Diabetes%20com%20M%C3%A9tricas%20de%20avalia%C3%A7%C3%A3o.ipynb) | Modelo de classificação para prever diabetes, avaliado com métricas como acurácia, precisão e revocação |
| [Redução de dimensionalidade em imagens](./Machine%20Learning/Reducao%20de%20Dimensionalidade%20em%20Imagens.ipynb) | Redução de dimensionalidade de imagens |

**Tecnologias:** Python, YOLO, scikit-learn, Jupyter Notebook
